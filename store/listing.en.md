# WordBridge Chrome Web Store Listing - English

## Name

WordBridge

## Short Description

Select text and explain or translate it with AI, IPA, examples, related words, and speech.

## Full Description

WordBridge is a Chrome extension for language learning and everyday reading. Select a word, phrase, or sentence on any webpage, and WordBridge uses your own OpenAI-compatible chat API to explain or translate it according to your source and target language settings.

Key features:

- Lightweight popup after selecting text on a webpage
- Supports words, phrases, and sentences
- Uses simple English explanations in English-to-English mode
- Supports source language auto-detection and multiple target languages
- Shows IPA, example sentences, synonyms, and antonyms
- Shows compact sentence structure analysis for sentence selections
- Uses the browser's built-in speech synthesis
- Customizable trigger modes: selection, modifier selection, or modifier double-click
- Configurable popup closing behavior: close on mouse leave or close only with X
- Supports OpenAI-compatible API Base URL, API Key, and chat model settings
- Caches recent lookups locally for 10 minutes to reduce duplicate API requests

Privacy summary:

WordBridge does not provide a hosted translation service, does not collect browsing history, does not sell data, and does not track users. When you trigger a lookup, the selected text is sent only to the OpenAI-compatible API endpoint that you configure. API keys and settings are stored in Chrome extension storage. Translation cache entries are stored locally and expire after 10 minutes by default.

Best for:

- Reading English webpages, papers, and documents
- Language learners who want simple English explanations
- Users who want to use their own AI API provider
- Readers who prefer a lightweight selection popup without interrupting the page
