# WordBridge Chrome Web Store Listing - 中文

## 名称

WordBridge

## 简短描述

选中文字，用大模型解释、翻译、显示音标、例句、近义词并朗读。

## 详细描述

WordBridge 是一个面向语言学习和日常阅读的 Chrome 扩展。你可以在网页上选中单词、短语或句子，WordBridge 会调用你自己配置的 OpenAI 兼容大模型接口，按源语言和目标语言设置生成简洁解释或翻译，并在页面中直接显示结果。

主要功能：

- 选中网页文字后弹出轻量解释浮层
- 支持单词、短语和句子
- 英英模式下使用简单英文解释
- 支持源语言自动识别和多目标语言
- 显示 IPA 音标、例句、近义词、反义词
- 句子模式下显示简洁句子结构分析
- 使用浏览器内置语音朗读
- 可自定义触发方式：自动选中、修饰键选中、修饰键双击
- 可选择浮层关闭方式：鼠标移出关闭或只点 X 关闭
- 支持 OpenAI 兼容 API Base URL、API Key 和模型名
- 本地缓存最近 10 分钟查询，减少重复 API 请求

隐私说明：

WordBridge 不提供内置翻译服务，不收集、不出售、不追踪你的浏览数据。插件只在你触发翻译时，把选中的文本发送到你自己配置的大模型 API 服务。API Key 和设置保存在 Chrome 扩展存储中，翻译缓存保存在本地并默认 10 分钟过期。

适合人群：

- 阅读英文网页、论文、文档的人
- 需要英英解释的语言学习者
- 希望用自己的大模型 API 做翻译和解释的用户
- 需要轻量、不打扰阅读流程的选词工具用户
